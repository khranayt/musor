# NEON DRIFT

A fast, mobile-first neon arcade survival game. No framework, build step, or dependencies required.

## Play

Open **[the game](https://khranayt.github.io/musor/)** on a phone or desktop.

- Drag your finger or mouse to steer the ship.
- Dodge the red debris.
- Collect cyan energy shards for bonus points.
- Survive, beat your high score, and reach the next sector.
- Pause with the on-screen button or **P / Esc**.

## Run locally

Open `index.html` in a browser, or serve this folder with any static HTTP server.

## Tech

- Vanilla HTML, CSS, and JavaScript
- Canvas rendering with responsive high-DPI sizing
- Pointer Events for touch and mouse controls
- Local Storage for your personal best
- No install, build tools, or external game libraries

## Deploy

The repository is ready for GitHub Pages: in **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
